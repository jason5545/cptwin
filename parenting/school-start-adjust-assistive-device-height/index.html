開學了~孩子長高囉...輔具也要記得長高喔~~

舜英・2017/9/14・約 3 分鐘讀完

這篇在「輔具與無障礙」・寫這篇時，雙胞胎約 20 歲

開學了～～

孩子們一個暑假不見  回學校時應該都長高長大了吧～～

身障孩子們在學校最常使用的行動輔具為手杖、拐杖、站立架、輪椅、擺位椅與助行器

(圖一)  (圖二) 因此在開學時，我們容易見到服務學校系統『巡迴治療師們』(不論是職能治療師、物理治療師)

記得喔...不論是否會進學校遇見巡迴治療師，一定要請治療師們在遇見孩子們時

先檢查一下輔具的使用情形

檢視一下看看輔具是否需要也調高  或因為使用了一學期有些地方已磨損些需要做更換或是需要更新重新訂製一個

例如：

  • 柺杖頭底部的防滑膠頭

★雖屬消耗品但是用久了會磨損  摩擦力變小止滑較差  在下雨天或地板濕滑就要小心怕滑倒。

(孩子們的行動力與協調能力原本就比較差了，可千萬別跌倒呀)

) 

  • 檢視一下助行器，是否應該跟著身高一起調高一格  (通常是半年至一年調整一次  每一格是1英吋約2.5cm) 或是助行器的輪子也要定期加點潤滑油隔絕水氣避免生鏽，或是孩子有覺得比較難拉動時，是否有頭髮、灰塵等其他東西卡在輪子上，適時的清除附著在輪軸上的異物，順勢整理清潔一下。

★建議遇見治療師時可以問問如何調整高度，或是拿助行器輔具的正確使用位置，讓自己學習如何調整一下呀，也可隨時注意孩子的狀況。

  • 還有特製擺位(輪)椅，擺位(輪)椅故名擺在正確位置的(輪)椅，坐姿才正確，輔具中心在製作特製(輪)椅是一定會留有一定的座寬與坐深，以備孩子得太快  有空間可調整，還不至於不可堪用。

★特製擺位(輪)椅的調整比較需要多面向看，所以還是請教巡迴治療師幫看看調整，不過簡單的頭靠或側撐高度也可問問治療師怎麼調整，其他輪椅需要調整的部位例如：

➤頭靠深度、高度、仰角

➤側支撐深度、高度

➤輪椅坐深(坐寬比較少調整)

(例如下圖：輪椅背靠多數會是二塊泡綿厚度要增加坐深只要拔抽一塊泡棉即可)

➤小腿支撐與腳踏板高度

➤煞車鬆緊度

➤螺絲是否容易鬆動或是已經脫落不見

其他的還有

  • 站立架的調整(這也需要專業治療師教導一下綁帶的位置) 或是電動站立架電池用法是否異常
  • 如果是電動輪椅則更要注意輪胎紋路深度 輪椅速度快  以防地板濕滑至輪胎打滑、電瓶使用狀況、或是電輪有開開停停的狀況
  • 坐墊是否需要減壓設備

其實把這些用的到的訊息學(背)起來 是對自己長知識或家人都有好處

了解輔具正確用法  正確使用、適時調整、進而方便善其事

一定要記得看看一下輔具

別讓它們從送來的第一天到不能使用時都是同一尺寸成為『萬年輔具』 來檢視一下學校輔具的同時(學校系統)

也可以找輔具資源中心(社政系統) 把居家的輔具也檢視一下喔
